# 🚴 Bike Sales Dashboard – Excel Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing customer demographics and behavioral data to understand factors influencing bike purchases. Using Microsoft Excel, I built an interactive dashboard that enables users to explore trends across income levels, age groups, commute distances, education, and regions.

The objective is to demonstrate strong fundamentals in **data cleaning, analysis, visualization, and storytelling** using Excel.

---

## 🎯 Objectives
- Identify key customer segments most likely to purchase bikes  
- Analyze the impact of income, age, and commute distance on purchases  
- Build an interactive dashboard for easy exploration of insights  
- Present data-driven insights in a clear and business-friendly format  

---

## 📊 Dataset Description
The dataset includes customer-level information such as:

- **Demographics:** Age, Gender, Marital Status, Education, Region  
- **Socio-Economic Factors:** Income, Occupation, Home Ownership  
- **Behavioral Factors:** Commute Distance, Number of Cars, Children  
- **Target Variable:** Purchased Bike (Yes / No)

---

## 🛠 Tools & Technologies
- Microsoft Excel  
  - Data Cleaning & Formatting  
  - Pivot Tables  
  - Pivot Charts  
  - Slicers  
  - Dashboard Design  

---

## 🔄 Data Preparation
- Removed duplicates and standardized column names  
- Converted income values to numerical format  
- Created derived features such as **Age Brackets**  
- Ensured consistency across categorical fields  

---

## 📈 Dashboard Features
### Interactive Filters
- Marital Status  
- Region  
- Education  
- Gender  
- Commute Distance  

### Visualizations
- **Average Income per Purchase** (by gender and purchase behavior)  
- **Customer Age Brackets vs Bike Purchase**  
- **Commute Distance vs Bike Purchase Trends**  

---

## 💡 Key Insights
- Middle-aged customers account for the highest bike purchases  
- Customers with short commute distances are more likely to buy bikes  
- Higher income groups show stronger purchase intent  
- Regional demand is higher in Europe and Pacific regions
